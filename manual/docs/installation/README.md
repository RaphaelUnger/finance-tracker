# Installation Documentation

Diese Dokumentation enthält alle Anleitungen und Guides für die Installation und Einrichtung der Finance Tracker App.

## Dateien:

- **INSTALLATION-GUIDE.md** - Vollständige Installationsanleitung mit Expo-Ansatz
- **QUICK-START.md** - Schnellstart-Anleitung (5 Minuten)
- **READY-FOR-ANDROID-STUDIO.md** - Android Studio Setup Guide
- **ANDROID-STUDIO-TEST.md** - Schritt-für-Schritt Android Studio Test
- **PACKAGE-VERSION-FIX.md** - Package-Version Kompatibilitätslösungen

## Verwendung:

Folgen Sie der INSTALLATION-GUIDE.md für eine vollständige Installation oder QUICK-START.md für eine schnelle Einrichtung.
