## 🚀 JETZT ANDROID STUDIO STARTEN!

### Schritt 1: Android Studio öffnen
- Falls nicht installiert: https://developer.android.com/studio

### Schritt 2: Projekt öffnen
1. **"Open an existing project"** klicken
2. **Navigieren zu:** `C:\Users\emila\IdeaProjects\finance-tracker\manual\android`
3. **"Open"** klicken

### Schritt 3: Gradle Sync abwarten
- **Wichtig:** Warten Sie 2-5 Minuten bis Gradle Sync fertig ist
- Unten rechts sehen Sie Fortschrittsbalken

### Schritt 4: Virtual Device erstellen
1. **📱 Device Manager** öffnen (rechts oben)
2. **"Create device"** → **Pixel 4** → **API 30**
3. **Emulator starten** (▶️ Button)

### Schritt 5: App ausführen
- **WICHTIG:** Stellen Sie sicher, dass Ihr Emulator in der Device-Dropdown ausgewählt ist
- **Grünen "Run" Button** klicken (▶️) - DIES INSTALLIERT DIE APP!
- **Oder:** Menü → Run → Run 'app'
- **Warten:** Build-Prozess dauert 1-3 Minuten
- **Finance Tracker App** wird automatisch installiert und gestartet!

### 🚨 WICHTIGER HINWEIS:
**Der Emulator allein startet KEINE App!** Sie müssen:
1. ✅ Emulator läuft
2. ✅ **Run-Button klicken** um die App zu bauen und zu installieren
3. ✅ App erscheint dann im Emulator

## 🔧 FALLS PROBLEME AUFTRETEN:

### "Emulator startet, aber keine App sichtbar"
**LÖSUNG:** Sie müssen die App erst bauen und installieren!
```
1. Grünen ▶️ Run-Button in Android Studio klicken
2. Warten bis "BUILD SUCCESSFUL" erscheint
3. App wird automatisch installiert und gestartet
```

### "Gradle Sync failed"
```
File → Sync Project with Gradle Files
```

### "SDK not found" 
```
File → Project Structure → SDK Location
Setzen auf: C:\Users\emila\AppData\Local\Android\Sdk
```

### "Build failed"
```
Build → Clean Project
Build → Rebuild Project  
```

### "No target device selected"
```
1. Device-Dropdown (neben Run-Button) öffnen
2. Ihren Emulator auswählen  
3. Run-Button klicken
```
