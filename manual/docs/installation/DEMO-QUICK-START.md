# 🚀 Demo Quick Start Guide

## ⚡ Finance Tracker Demo in 30 Sekunden starten

### Schritt 1: Demo-Verzeichnis öffnen
```bash
cd C:\Users\emila\IdeaProjects\finance-tracker\manual\demo
```

### Schritt 2: Dependencies installieren (falls nötig)
```bash
npm install
```

### Schritt 3: Demo starten
```bash
npm run web
```

**✅ Demo öffnet sich automatisch im Browser auf `http://localhost:8084`**

## 🔧 Demo anpassen:

### **Code ändern:**
- **Dashboard**: `app/(tabs)/index.tsx`
- **Transaktionen**: `app/(tabs)/transactions.tsx`
- **Berichte**: `app/(tabs)/reports.tsx`
- **Einstellungen**: `app/(tabs)/settings.tsx`

### **Hot Reload:**
- Änderungen werden sofort im Browser sichtbar
- Kein Neustart erforderlich
