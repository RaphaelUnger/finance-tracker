# 🚀 Finance Tracker - Demo Version

Dies ist die **Demo-Version** der Finance Tracker App, integriert in das manual Projekt.

## 🎯 Was ist das?

Eine vollständig funktionsfähige **Web-Demo** der Finance Tracker App mit:
- 💰 **Dashboard** - Saldo-Übersicht und Schnellaktionen
- 💳 **Transaktionen** - Detaillierte Transaktionsliste 
- 📊 **Berichte** - Ausgaben-Trends und Kategorie-Aufschlüsselung
- ⚙️ **Einstellungen** - Vollständige Konfigurationsmöglichkeiten

## 🚀 Demo starten

```bash
# In diesem Verzeichnis
cd C:\Users\emila\IdeaProjects\finance-tracker\manual\demo

# Dependencies installieren (falls nötig)
npm install

# Demo starten
npm run web
```

**➡️ Öffnet automatisch im Browser: `http://localhost:8084`**

## 📱 Mobile Demo

```bash
# QR-Code für Handy-Testing
npm start

# Expo Go App auf dem Handy installieren
# QR-Code scannen → Demo läuft auf dem Handy
```

## ✨ Demo-Features

### **Realistische Daten:**
- **Saldo**: €1.234,56 mit Wochenzuwachs
- **Transaktionen**: REWE, Shell, Gehalt, H&M etc.
- **Kategorien**: Lebensmittel, Transport, Kleidung, Gesundheit
- **Berichte**: Monatsübersicht mit Trends und Statistiken

### **Professional UI:**
- **Material Design Icons** für alle Funktionen
- **Touch-optimierte Navigation** mit 4 Tabs
- **Responsive Design** für Web und Mobile
- **Dark/Light Theme** Support
